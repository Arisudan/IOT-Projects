## How to use

Each project now follows a fuller profile-ready template with:
- badges
- overview and problem statement
- hardware and software requirements
- how it works
- screenshot sections
- enhancement ideas

Each folder now also includes a runnable starter file and a plain-language run guide with copy/paste commands for people who prefer command-line setup.

The newest five folders are capitalized for easier reading in GitHub and VS Code.

You can use each folder as an independent GitHub project repository or keep this workspace as a portfolio collection.
